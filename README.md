# OmniDesk
An autonomous workstation robot that tracks and follow user. Has exchangable modules to fit user's need such as soldering/multimeter/oscilliscope.

- Two Rechargeable Lead-Acid 12V Batteries in Series
- Two 189:1 ratio motors
- Nucleo-G474RE microcontroller board
- Autonomously follows user using Bluetooth tag
- Detects nearby objects using ultrasonic sensors
- Custom Designed Motor Driver
